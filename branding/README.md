# Marginalia artwork

The owner supplied both images. These PNGs are exact copies of the original extensionless files; no artwork was redrawn.

- icon.png: reading-room emblem, used for the application and Windows icon.
- wordmark.png: supplied stylized name, displayed with CSS cropping in the bookshelf and compact reader header.
- icon.ico: multi-resolution Windows derivative, generated mechanically from icon.png by electron-builder's icon converter.

Keep the source PNGs unchanged. Cropping in the interface removes surrounding empty space without modifying the artwork. The compact reader treatment preserves room for chapter navigation.
